# Three Pillars Lux

Primary domain: https://3PillarsLux.com

Open `index.html` in a browser to preview Home. The navigation opens Library and About. For an HTTP preview, run `python -m http.server 8000` from this folder and open `http://localhost:8000`.

- `index.html`, `library.html`, `about.html` are the primary pages.
- `styles.css` and `library.js` handle styling and Library controls.
- `assets/` contains the supplied Lexi illustration, optimized for this preview.
- `privacy.html` and `terms.html` are draft footer pages.

The Library has an empty catalog. Search and category selections display empty states. Article authoring and indexing are deferred until the three pages are reviewed.

For a future GitHub Pages launch, place this directory's contents in the approved publishing source and configure Pages to serve it. Review the legal drafts and check all routes on the Pages preview before configuring the custom domain. No deployment or DNS changes are needed for local review.
